Privacy policy

Unusual World Uploader · last updated 23 November 2026

Unusual World Uploader is a private tool used only by the owner of The Unusual World channel to upload that channel's own videos to YouTube.

What the app accesses

With the account owner's permission, the app uses the YouTube Data API scope youtube.upload to upload videos and set their title, description, tags and privacy status. It does not read, collect or store any other data from Google accounts.

How data is stored

The access token is stored only on the owner's own computer. No data is sent to any other server, sold, shared, or used for advertising.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Uploading uses YouTube's API Services under the YouTube Terms of Service and the Google Privacy Policy.
